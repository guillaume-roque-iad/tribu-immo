Site tribu-immo.com - deploiement automatique via Cloudflare Workers Builds.

Performance : après modification de redesign.css ou languages.css, exécuter `node scripts/inline-home-styles.mjs` pour synchroniser les styles intégrés des pages d’accueil. La construction Cloudflare le fait aussi automatiquement. Les fichiers sous assets/optimized sont immuables : utiliser un nouveau nom pour toute modification.

Indexation : `node scripts/update-indexing.mjs` applique la même politique après génération des traductions et lors de chaque build. Option A : seules les pages publiques françaises sont indexables. Les pages EN/ES/IT/DE/PT restent accessibles avec noindex, follow et hors sitemap. Une liste blanche vide dans scripts/update-indexing.mjs prépare la réactivation des seules traductions relues. Les confirmations, la page 404, le simulateur intégré et les contenus migrés restent exclus. Le script synchronise les URL canoniques et les sitemaps. Les cinq sitemaps traduits sont conservés vides et le sitemap index référence seulement sitemap-fr.xml. Aucun groupe hreflang ni x-default n’est émis sans équivalent traduit indexable. lastmod provient de dateModified ou d’une date éditoriale affichée ; il est omis si aucune date fiable n’est disponible. Une modification du HTML ou un build ne crée pas de date éditoriale. `i18n/reviewed-pages.json` suit uniquement la relecture éditoriale, sans bloquer Google.

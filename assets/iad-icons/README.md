# Iconographie iad

Source : charte iad 2025 fournie par Guillaume le 13 septembre 2026, pages 18 et 19. Tracés SVG extraits du PDF et déjà utilisés sur elodie-cimiotta-iad.com.

Illustrations (p. 18) : home, check, growth, team, alert. Pictogrammes (p. 19) : mail, location, key, globe, document.

Préserver les couleurs #00B4EC et #EA584A et les proportions (object-fit:contain ou background-size:contain). Réutiliser les mêmes fichiers dans toutes les langues. Ne pas ajouter d’emojis système décoratifs ni de dessins génériques de remplacement. Les pictogrammes CSS accompagnent des textes explicites et sont décoratifs. Les flèches des liens restent des indicateurs de navigation.
